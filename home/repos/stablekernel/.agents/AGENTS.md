# Stablekernel Organization Context

## Environment
- Organization: stablekernel

## Grayboard
- Do not call the Grayboard `bind` tool or run `/grayboard-enroll` on your own initiative, including at session start or when another tool suggests it.
- Bind a session only when the user explicitly asks, using the name they give. Do not create a new name unless they ask for that too.
- If a task looks like it needs Grayboard and the session isn't bound, ask the user instead of binding.
